01 / WHY THIS EXISTS

A note is more than a frequency.

Musicians hear attack, sustain, timing, resonance, mistakes, feel, and the way one sound leans into the next. A transcription system has to begin with notes — but the reason to build it is the music around those notes.

Modern learning tools become much more interesting when the instrument does not need a pickup, a MIDI output, or special proprietary hardware. The research question is whether ordinary recorded sound can become a reliable enough interface for meaningful musical feedback.

Acoustic guitar is the first controlled test case because it exposes exactly the problems that make real music difficult: overlapping harmonics, ringing strings, chords, pick attack, room reflections, tempo, dynamics, and human timing.

02 / METHOD

Start simple. Preserve the evidence.

01

Capture

Record controlled real performances with the same instrument, microphone, format, and documented conditions.

02

Baseline

Run an unchanged pretrained model first so later work has a fixed reference point.

03

Measure

Compare predictions to known ground truth using pitch, onset, error, and runtime metrics.

04

Investigate

Identify specific failure modes before changing data, architecture, thresholds, or training.

05

Adapt

Use documented real data, appropriately licensed datasets, and synthetic data only after the baseline is preserved.

06

Hold out reality

Judge improvements on unseen real recordings rather than on material used to train or tune them.

CURRENT RULE

Incomplete runs are not results.

The first stock Basic Pitch attempt was stopped after an abnormally long CPU-only inference run. The recording was preserved unchanged and no transcription accuracy claim was made. The next step is to validate the execution backend and produce a scoreable report.
